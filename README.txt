# PROMIXOR Python

O **PROMIXOR Python** é uma versão desktop do projeto PROMIXOR desenvolvida em **Python**, com foco em simulação, prototipagem e organização de projetos eletrônicos através de uma interface gráfica simples e intuitiva.

O projeto foi criado com o objetivo de reunir diferentes ferramentas relacionadas à eletrônica e programação em um único ambiente, permitindo que o usuário monte projetos, configure componentes e visualize informações de forma mais organizada.

---

## Sobre o projeto

O PROMIXOR surgiu como uma ideia de plataforma para auxiliar na criação e visualização de circuitos e projetos eletrônicos.

Esta versão utiliza **Python** para oferecer uma aplicação desktop mais leve e de fácil execução.

A interface foi desenvolvida utilizando bibliotecas gráficas do Python, permitindo criar janelas, menus, botões, painéis e diferentes áreas de trabalho.

O projeto continua em desenvolvimento e diversas funcionalidades estão sendo adicionadas e aprimoradas.

---

## Principais funcionalidades

Atualmente, o PROMIXOR Python possui recursos como:

* Interface gráfica desktop;
* Tela inicial do sistema;
* Navegação entre diferentes áreas da aplicação;
* Organização de componentes eletrônicos;
* Área destinada à criação de projetos;
* Interface para montagem e visualização de circuitos;
* Seleção de componentes;
* Sistema de menus e botões;
* Área de código;
* Gerenciamento básico de projetos;
* Interface adaptada para facilitar a utilização;
* Modo de visualização 3D demonstrativo.

---

## Modo 3D

O PROMIXOR possui uma área de **visualização 3D**.

Na versão Python atual, esse recurso funciona principalmente como uma representação visual da proposta do sistema.

O modo 3D ainda não possui uma engine completa de montagem ou simulação física dos componentes.

Ele demonstra como a interface e a visualização tridimensional poderão funcionar em versões futuras do projeto.

O objetivo principal do PROMIXOR é facilitar o desenvolvimento de projetos eletrônicos, reunindo em um único programa ferramentas relacionadas a:

## Instalação

Primeiro, tenha o **Python** instalado no computador.

Depois, instale as dependências necessárias.

Exemplo:

```bash
pip install customtkinter pillow
```

Caso novas bibliotecas sejam utilizadas pelo projeto, elas também deverão ser instaladas.

---

## Executando o projeto

Abra o terminal dentro da pasta do PROMIXOR e execute:

```bash
python main.py
```

Dependendo do nome do arquivo principal do projeto, substitua `main.py` pelo nome correspondente.

Exemplo:

```bash
python promixor.py
```

---

## Versão executável

O PROMIXOR Python também pode ser distribuído como uma aplicação para Windows.

O programa pode ser empacotado utilizando ferramentas como:

```text
cx_Freeze
```

ou

```text
PyInstaller
```

Isso permite executar o PROMIXOR em computadores Windows sem precisar abrir o código manualmente pelo terminal.
